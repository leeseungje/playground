# 🎮 사내 플레이그라운드 (playground)

사내망에서 동료들과 즐기는 게임 모음입니다. 가상 칩·점수만 쓰고 실제 돈이나 환전 가능한 포인트는 쓰지 않습니다.

| 게임 | 주소 (서버 PC 기준) |
|---|---|
| ♠ 텍사스 홀덤 | `http://서버주소:7777/` |
| 🏇 사내 경마 | `http://서버주소:7777/race/` |
| 🕵️ 라이어 찾기 | `http://서버주소:7777/liar/` |

입구 페이지: https://leeseungje.github.io/playground/

## ♠ 텍사스 홀덤

- 방을 만들고 초대 링크를 Teams 채팅방에 붙여 넣으면 같이 할 수 있어요.
- 내 패는 나만 보입니다. 다른 사람의 패는 쇼다운이나 올인 공개 전까지 **서버가 아예 보내지 않습니다.**
- 딜러는 NPC(서버)가 맡습니다. 셔플(암호학적 난수), 블라인드, 차례, 사이드팟, 족보 판정을 모두 처리해요.

## 🏇 사내 경마 (`/race/`)

같은 서버에서 `http://서버주소:7777/race/` 로 들어가요. 한국 경마의 마권·배당 규칙을 따르는 가상 칩 경마예요.

- **마권 7종**: 단승식·연승식(8두 이상 3착, 7두 이하 2착)·복승식·쌍승식·복연승식·삼복승식·삼쌍승식
- **배당**: 파리뮤추얼(승식별 매출 × 환급률 80% ÷ 적중 금액). 배당판이 실시간으로 바뀌고 발매 마감 때 확정돼요. 사람이 적어도 배당이 성립하도록 NPC 기본 매출을 깔아 둬요. 최저 배당 1.0배.
- **출주표**: 출전 8~12두, 경주 거리 1000~1800m, 주로 상태(건조·양호·다습·불량), 부담중량, 마체중과 증감(▲증가·▼감소), 최근 3전, 말 별명·소개, 기수 소개·주행 스타일·통산 성적
- **발주 직전 출전 취소**가 나면 그 말이 들어간 마권은 환불돼요.
- **돌발 이벤트**: 부스트(커피·로켓·방귀), 넘어짐, 충돌, 졸음, 역주행. 서버가 결과와 함께 정하므로 모두에게 같은 장면이 나오고 실제 순위에 반영돼요.
- 결과는 **발매 마감 순간**에 서버가 암호학적 난수로 처음 정해요. 그 전에는 경주 기록이 화면으로 가지 않아요.
- 발매 시간 기본 1분 (방장이 ⚙에서 15초~3분으로 조절)

## 🕵️ 라이어 찾기 (`/liar/`)

3~12명이 함께하는 파티 게임이에요. 한 명(설정에 따라 두 명)만 제시어를 모르고 카테고리만 알아요.

- 진행: 카드 확인 → 돌아가며 힌트(글 또는 「말로 했어요」) → 자유 토론 → 투표(동표면 한 번 재투표) → 라이어가 지목되면 12개 보기 중 제시어 맞히기
- 점수: 시민 승리 시 시민 +1, 라이어 승리 시 라이어 +3
- 바보 모드: 라이어도 다른 제시어를 받아 자기가 라이어인 줄 몰라요
- 카테고리: 음식·동물·직업·장소·스포츠·물건·사내 생활 (무작위 가능)
- 제시어는 서버가 시민에게만 보내요. 라이어 화면으로는 전달되지 않아요.

## 입구 페이지 (GitHub Pages)

https://leeseungje.github.io/playground/ 는 게임을 고르고 서버로 안내하는 입구입니다. 저장소 루트의 `index.html` 이 그 페이지예요.

- 게임 화면의 「초대 링크 복사」는 이 주소로 링크를 만들어요. 열면 1.5초 뒤 그 게임의 방으로 바로 들어갑니다.
  - 홀덤 `?room=AB12`, 경마 `?game=race&room=AB12`, 라이어 `?game=liar&room=AB12` (서버 포트가 다르면 `&port=7778`)
- 서버 PC의 IP가 바뀌면 `index.html` 의 `GAME_SERVER` 값만 고쳐서 올리면 됩니다.
- Pages는 **main 브랜치 / (root)** 에서 배포합니다 (Settings → Pages → Deploy from a branch).

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start
```

켜지면 이렇게 나와요.

```
홀덤 서버가 켜졌어요.
  내 PC:   http://localhost:7777
  사내망:  http://172.x.x.x:7777   ← 이 주소를 동료에게 공유하세요
```

포트를 바꾸려면 `PORT=4000 npm start`(PowerShell은 `$env:PORT=4000; npm start`)로 실행하세요.

## 하는 방법

1. 닉네임을 넣고 **새 테이블 만들기**를 누릅니다.
2. 위쪽의 **초대 링크 복사**를 눌러 채팅방에 붙여 넣습니다.
3. 2명 이상 모이면 방장이 **게임 시작**을 누릅니다. 이후 판은 자동으로 이어집니다.
4. 자유 게임에서 칩을 다 잃으면 판과 판 사이에 **칩 다시 받기**를 누를 수 있어요.

### 방 설정 (⚙, 방장만)

| 항목 | 기본값 | 범위 |
|---|---|---|
| 모드 | 자유 게임 | 자유 게임 / 토너먼트 |
| 시작 칩 | 1,000 | 100 ~ 1,000,000 (빅블라인드의 10배 이상) |
| 빅블라인드 | 20 (스몰은 절반) | 2 ~ 100,000 |
| 차례 제한 시간 | 30초 | 10 ~ 120초 (넘기면 체크, 체크할 수 없으면 폴드) |
| 블라인드 상승 주기 | 8판 | 2 ~ 50판 (토너먼트만) |

- **토너먼트**: 시작할 때 접속한 사람 모두 같은 칩으로 출발하고, 정해진 판 수마다 블라인드가 올라요. 칩이 떨어지면 탈락하고 순위가 매겨지며, 마지막 1명이 우승해요. 중간에 들어온 사람은 구경만 해요.
- 최대 인원은 9명이에요.

### 화면

- 카드 딜·뒤집기, 칩 이동, 쇼다운 순차 공개, 승자 배너 연출과 효과음 (🔊 로 끄기)
- 하단 왼쪽에 **지금 내 족보**가 나오고, 족보를 만드는 카드는 테이블에서 빛나요.
- **미리 선택**: 내 차례 전에 체크/폴드·체크·콜·무조건 콜을 골라 두면 차례가 왔을 때 자동으로 처리돼요.
- **단축키**: F 폴드, C 체크/콜, R 레이즈, A 올인(두 번), ↑↓ 레이즈 금액, Enter 채팅
- 옆 패널: 채팅·이모지, 판 기록(공개된 패만), 순위(칩·손익·승률), 딜러 기록
- 휴대폰 세로 화면도 지원해요.

- 같은 브라우저라도 **탭마다 다른 플레이어**가 됩니다. 혼자 여러 탭으로 테스트할 수 있어요.
- 새로고침하거나 잠깐 연결이 끊겨도 같은 탭이면 같은 자리로 돌아옵니다.

## 구조

```
server/
  index.js   HTTP(정적 파일) + socket.io 이벤트
  game.js    방·한 판 진행(NPC 딜러). 플레이어별 화면 상태는 viewFor() 에서만 만든다
  cards.js   덱 셔플
shared/
  hand-eval.js   족보 판정 (서버와 브라우저가 함께 씀)
public/          화면 (빌드 없는 HTML/CSS/ES 모듈)
  js/table.js    테이블 무대·좌석·카드·칩 연출
  js/actions.js  하단 행동 버튼·미리 선택·단축키
  js/panels.js   채팅·기록·순위·방 설정
  js/sound.js    효과음 (Web Audio 합성, 파일 없음)
test/            족보·규칙·토너먼트·무작위 3000판 시뮬레이션·소켓 통합 테스트
```

## 알아 둘 점

- 서버를 켠 PC가 꺼지거나 잠들면 게임도 멈춥니다. 방 정보는 메모리에만 있어서 서버를 다시 켜면 사라져요.
- GitHub Pages 같은 정적 호스팅에서는 동작하지 않습니다. 실시간 서버(WebSocket)가 필요해요.
